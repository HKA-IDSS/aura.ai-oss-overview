# aura.ai – GitHub Pages Site (EN)

Static single-page site listing open-source repositories from the aura.ai project.

## How to deploy on GitHub Pages
1. Create a new GitHub repository (e.g., `aura-ai-pages`).
2. Copy the files from this folder into the repository, commit and push.
3. On GitHub go to **Settings → Pages**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` → `/root`
4. After ~1 minute the site will be available at `https://<username>.github.io/<repo>/`.
